# Implémenter une classe

Implémente la classe `$ARGUMENTS` en suivant strictement :

1. **Lire** `docs/specifications/specifications.md` pour la description
2. **Lire** `docs/architecture/uml/pdf-converter-classes.puml` pour les attributs/méthodes
3. **Créer** le fichier selon `docs/specifications/structure-projet.md`
4. **Coder** la classe avec tous les attributs et méthodes UML
5. **Écrire** les tests dans `tests/test_{classe}.py`
6. **Exécuter** `pytest tests/test_{classe}.py -v`
7. **Afficher** le résultat des tests
8. **Demander** validation avant de continuer

⚠️ NE PAS passer à une autre classe sans validation explicite.
